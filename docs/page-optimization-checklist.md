# Page Optimization Checklist

Use this before publishing or updating any SEO/GEO target page.

## Search Basics

- [ ] Page has one clear target topic.
- [ ] Title includes product/category and buyer intent.
- [ ] Meta description explains value and contains a natural keyword.
- [ ] H1 is specific and matches the page topic.
- [ ] H2 sections answer real buyer questions.
- [ ] URL is short, readable, and stable.
- [ ] Images have descriptive alt text.
- [ ] Important product pages link to related products, downloads, and contact options.

## Product Content

- [ ] Product model name is visible.
- [ ] Meter type is clear.
- [ ] Communication method is clear.
- [ ] Application scenario is clear.
- [ ] Buyer fit is clear.
- [ ] Specs or downloads are easy to find.
- [ ] Claims are specific and defensible.

## GEO Readiness

- [ ] Page contains at least one direct answer paragraph.
- [ ] Entity names are consistent: Shenzhen Calinmeter Co., Ltd., CalinMeters.
- [ ] Technical terms are written in full before abbreviations where useful.
- [ ] FAQ content is concise and answer-focused.
- [ ] The page can be understood without relying on images alone.

## Structured Data Candidates

- [ ] Organization
- [ ] Product
- [ ] BreadcrumbList
- [ ] FAQPage

## Validation

- [ ] `npm run build` passes.
- [ ] Page renders correctly on desktop and mobile.
- [ ] Links, PDFs, contact form, WhatsApp, and WeChat are usable.
- [ ] Search Console inspection is requested for important new pages.
