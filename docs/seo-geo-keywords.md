## Weekly Selection Rule

Pick 3-5 related queries each week and map them to one existing canonical owner. Use Search Console query, country and landing-page data before adding regional content. If the selected queries expose a genuine unanswered buyer question, improve the owner page or publish a sourced supporting article; do not force unrelated terms into existing copy.
